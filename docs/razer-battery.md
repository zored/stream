# Проверка заряда Razer на Mac

Подключите устройство кабелем USB с передачей данных или через донгл 2,4 ГГц. Для проверки BLE включите Bluetooth, подключите устройство и разбудите его. Из корня репозитория запустите:

```sh
tools/razer-battery 2>&1
```

Нужны Apple Command Line Tools (`xcode-select --install`, если Swift ещё не установлен). Synapse не нужен. Если macOS спросит доступ к Bluetooth, разрешите его терминалу.

Пришлите king весь вывод и укажите, как подключили устройство: кабель, донгл или Bluetooth. Если пробуете несколько режимов, запускайте команду отдельно для каждого.

- **USB и донгл:** для VID `0x1532` проба читает HID feature report `07/80` по [протоколу OpenRazer](https://github.com/openrazer/openrazer/blob/master/driver/razercommon.c). Донгл с обычным USB-именем в выводе может называться `USB`. Заряд появится у моделей, которые отвечают на этот запрос. [Stream Controller и Controller X](device.md) определяются по USB, но этот протокол не используют.
- **BLE:** проба читает Battery Level `2A19` в сервисе `180F`. PID берётся из PnP ID или системного HID, если macOS видит эти данные. Устройство без этих данных может определиться по имени или Bluetooth Company ID; PID тогда может остаться неизвестным. Классический Bluetooth без BLE Battery Service не даёт показания.

## Подключение к тайлу после проверки

`tools/razer-battery --json` пишет в stdout массив устройств: `model`, `transport`, `pid` (число, если известен), `batteryPercent` (целое 0–100 при успешном чтении), `error` (если заряд не прочитан). Пустой массив `[]` означает, что устройства не найдены. Подсказки идут в stderr.

После проверки реального устройства выбрать подтверждённые PID и транспорт. Запускать пробу из демона `zored_stream` только при включённом флаге, с таймаутом и редким опросом. Передавать показание через custom variable Companion; при ошибке или пропаже устройства сбрасывать старое значение. Тайлы и флаг в этой правке не меняются.
