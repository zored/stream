# Codex Desktop на контроллере

## Цель

Дополнить существующую поддержку Claude чатами Codex Desktop. Когда Codex Desktop в фокусе, показывать и выбирать его модель и effort. Не менять существующие действия Claude при его фокусе.

## Поведение

- Общий тайл содержит подходящие чаты Claude и Codex; кружки и квадраты сохраняют существующее значение, активный чат выделен кольцом. Переход по общему списку открывает выбранный чат.
- Цвет источника: светло-оранжевый для Claude, светло-изумрудный для Codex. Состояния работы, ожидания ответа, завершения и прочтения должны оставаться различимы на устройстве; точные оттенки и способ обозначения состояний определить после проверки контраста.
- При фокусе Codex физические кнопки 1–8 отвечают на поддерживаемые карточки вопросов чата, используя существующий режим выбора и его индикацию. Пока карточка активна, собственные действия кнопок приостанавливаются; при её отсутствии или недоступности демона возвращаются. Разрешения на выполнение команд в объём этого требования не входят.
- При фокусе Codex переключатель предлагает `6.1 Terra` и `6.1 Sol`, effort `low`, `medium`, `high`. Отображается фактический выбор; неподдерживаемое значение не подменяется другим.
- Сохраняются защита от отправки действий не тому приложению, индикация ошибки, поведение Claude и правила проекта для открытых чатов. Возможность и границы безопасного применения в Codex необходимо проверить до реализации.

## Подход

Предпочтительно читать актуальное состояние и управлять через доступный интерфейс приложения и локальные источники. Альтернатива — события хуков: применять только если источник необходимого состояния иначе не найден; существующий `notify` и настройки пользователя сохранять, глобальные конфиги не менять без отдельного согласования. Не считать API инструментов, доступных внутри чата, автоматически доступным внешнему демону.

## Ограничения

Исследование не меняет чаты, глобальные настройки и модель. Неподтверждённые возможности помечаются как таковые; отсутствие данных не изображается достоверным статусом. Проверка на контроллере необходима для цветов и ввода. Лимиты Codex в объём не входят.
