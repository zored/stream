1. Верхний уровень

Три слоя, у каждого одна роль (инвариант A1): Companion рисует и запускает действия, zored_stream владеет состоянием и всеми вызовами ОС, медиаклавиши тоже (:47113/key/*). Связь только двумя способами: Companion → демон curl -fsS -m 1 -X POST http://127.0.0.1:<port>/… в exec; демон → Companion POST :8000/api/custom-variable/<name>/value. verified

  • Демон шлёт только изменившиеся значения и раз в 10 с (resendEvery) всё заново — Companion после рестарта лечится сам (A4). verified
  • Форк zored/companion-surface-loupedeck (ветка zored_stream): вибрация, позиция пальца на стрипе, POST в демон напрямую (/volume/drag, /ai/slide) (A10). verified роуты в main.go, остальное assumed
  • Один процесс держит serial-порт: Companion, Loupedeck app или tools/sniff.py (A8). assumed

2. Companion: страницы как код

  • make deploy = make pages → node tools/deploy.mjs --vars companion/custom-variables.json media-page…:1 test-page…:2: чанки по 64 КБ, sha1, importExport.prepareImport.*. Перезаписывает страницы 1 и 2 — деплоит один (A7). verified
  • companion/* — только build output, детерминированный; CI делает make check + git diff --exit-code companion (A5). verified
  • Кастомные переменные — контракт: каждая $(custom:x) есть в custom-variables.json профиля, всё, что ставит демон, есть в mac-профиле (A3). assumed (проверка в check_contract.py, не читал целиком)
  • Профили: gen_pages.py companion (mac) и gen_pages.py companion/windows windows. Windows только выкидывает ячейки/переменные (call_cam, ym_like, dictation, power_svg) , медиаклавиши в обоих через :47113/key/*; mac-вывод от этого не меняется (A6). verified профили, детали assumed
  • Кнопка — button-layered: слои canvas/box/text, выражения $(custom:x), наборы down/up/rotate_left/rotate_right, hold = числовой набор "400" в runWhileHeld. LED RGB-кнопки = фон кнопки. assumed

4. Механизмы

4.1 Choice mode — гейт и fallback

Пока на экране карточка вопроса / permission / next-step box во фронтовом Claude Desktop или iTerm2, кнопки 1–8 отвечают на неё; своё действие пропускается (F1–F3). Release принадлежит своему press (F2).

  • Приоритет: question card > permission card > next-step box. LED через цвет box0: red = активна, green = выбрано, white = primary. assumed
  • Тесты TestChoiceGate, TestChoiceAction, TestChoiceLEDs; CI проверяет, что все row-3 действия гейтятся с fallback. assumed (имена из invariants.md)
  • CLI в iTerm2: опции из hook JSON (tool_input.questions), ответ печатается в сессию по unique id. assumed

4.2 Звонки — gRPC VK WorkSpace

  • LED показывает только то, что сообщил VK WS (on/off/pending/unknown/none), никогда локальный toggle; без звонка 409 (F4). assumed
  • Push-to-talk: hold ≥ 300 мс, считается в демоне по времени down/up (F5). assumed
  • EndCall адресуется hdr.callId; без reqId в Header — errorCode 400. assumed

4.3 AI limits + model switch

  • Лимиты не тратят токены: только GET /api/oauth/usage, никакого claude CLI; refresh пишет только Claude Code-credentials, остальные поля сохраняет (F11). assumed
  • Устаревшее серое: fetch упал / не было / старше 2 интервалов; лимит после resets_at сбрасывается (F10). Прокси через -usage-proxy (Go не понимает PAC). verified флаг
  • Модель меняется только на new-chat экране Desktop во фронте; иначе 5 с серого превью; read-back расходится → error (F12). assumed

4.4 Диктовка с паузой музыки

  • Жесты: hold = push-to-talk, tap = старт, tap = стоп+отправка, hold во время записи = стоп без отправки. Пустой транскрипт не шлётся (F9). assumed
  • Музыка: явные pause/play через stdin perl-хелпера, не toggle; resume только если ничего не играло (с 2 с после паузы) (F8, тест TestDictationMusic). assumed

4.5 Agents waiting — hooks + Desktop unread

  • Хуки ставит make agent-hooks (tools/agent_hooks.py) в ~/.claude/settings.json; никогда не блокируют агента (S2, проверяет CI). verified цель Makefile
  • Desktop "done" снимается только когда файл сессии говорит "прочитано" — не SessionEnd, не мёртвый pid, не рестарт демона (F14). assumed

4.6 Scroll / Ctrl+Tab — Ctrl всегда отпускается

F6, F7, S1: тесты TestScrollTabReleasesCtrl, TestScrollPressReleasesCtrl, TestScrollSignalReleasesCtrl, TestScrollModes. Press + turn = горизонталь. verified роуты, assumed тайминги

4.7 Keep-awake (Amphetamine)

power.go: тайминги в демоне (не 400 мс hold Companion), состояние из Amphetamine через osascript каждые 2 с (F16, S4). Сон ни разу не триггерился. assumed

4.8 Захват крутилки справа, ряд 1

Крутилка по умолчанию = яркость Mac (hold = яркость контроллера). Power и wi-fi временно её перехватывают: verified в main.go:

/brightness/up:  if pw.turn(1) || wf.turn(1) { return br.level() }  else br.turn(1)

Ответ всегда = яркость контроллера текстом, Companion пишет её в ctl_brightness и делает set_brightness (пол 10 %, F17).

4.9 Headphones route

  • /headphones/toggle возвращается сразу, переключение в фоне. On: IOBluetoothDevice openConnection к Accentum, ждать до 10 с CoreAudio-устройство, default output+input. Off: output = Logi* иначе built-in, input = USB иначе built-in, closeConnection. assumed
  • Авто-роут: опрос 2 с, новый Logi*/USB, пока output не Bluetooth → колонки. Только на появление — ручной выбор не перебивается. assumed
  • Нужен NSBluetoothAlwaysUsageDescription в Info.plist, вшитом через -sectcreate __TEXT __info_plist. Тайл: жёлтый при переключении, красный 3 с при ошибке. assumed

4.10 Wi-fi scan через helper app

  • Почему open: дочерний процесс наследовал бы grant демона (его нет); без Location все источники SSID редактированы. assumed
  • Hold ≥ 400 мс = питание; touch = 5 с выбора сети крутилкой (захват, 4.8); join только после 2 с на другой сети (F21, тесты TestWifiOrder, TestScanNetworks). verified роуты, поллы wifiPollEvery/wifiProbeEvery

4.11 Now Playing, seek, рендер стрипа

  • Perl: с macOS 15.4 MediaRemote ничего не отдаёт сторонним процессам; Apple-подписанный perl с нужным entitlement — отдаёт. Ребёнок перезапускается через 1 с. assumed; флаги -nowplaying-script/-nowplaying-lib verified
  • Seek: цель клампится в 0 … duration − 1 с, последняя цель всегда уходит (F18). Стрип 48×258, 6 % inset, 3 ячейки = 3 рендера на кадр (D2, D3, P3). assumed
  • Общий бар левого стрипа (bar.go): volume / mac / ctl / seek, кто двигал последним. assumed

Процесс

  • Мастер-сессия ведёт PLAN.md и карту свободных контролов; каждая новая задача — свежая дочерняя сессия (R3).
  • Только одна сессия правит gen_pages.py или гоняет make deploy (A7).
  • Цикл: правка gen_pages.py → make deploy → make test → проверка входов (лог/custom_log), состояния (HTTP API), вида (:8000/buttons/1); стрипы и haptics — только на устройстве.
  • Коммит только своих путей: git -C <repo> commit -m main -- <paths>. Пользователь сам: make zored_stream-cert, make companion, make agent-hooks, TCC-гранты.
