# Emoji picker

Controls: [controls.md](controls.md#тайл-ряд-2-колонка-2--emoji-picker). Module `emoji` of `zored_stream`, port 47128.

## Flow

- `POST /emoji/tile` (тайл ряд 2, колонка 2): closed → open for 4 s; open → type the top emoji of the last used strip.
- Knobs: `/volume/{up,down,mute}` and `/brightness/{up,down,hold,release}` ask the picker first, like keep-awake / wi-fi do;
  closed, it takes nothing.
- Strips: the fork keeps sending `/volume/drag?dy=` (left) and `/ai/slide?y=` (right); while open the daemon routes them
  to the picker. The fork also posts every strip touch edge: `POST /emoji/start?s=l|r&y=` and `/emoji/end?s=l|r&y=`
  (ignored while closed). Tap = < 6 px of movement.
- Typing: `CGEventKeyboardSetUnicodeString` on a key down/up pair through the HID tap (S7) — the focused field, no clipboard.

## Data

- Recent: `EMFDefaultsKey.EMFRecentsKey` of `~/Library/Preferences/com.apple.EmojiPreferences.plist` via `plutil`,
  newest first, read on every open (verified). The picker never writes it.
- All: `emoji_data.go`, generated by `tools/gen_emoji.py` from Unicode `emoji-test.txt` 15.1, fully-qualified, no skin
  tones, Apple's category order.

## Motion and rendering

- Offset in items; a drag moves it 1 : 1 (43 px pitch); release with ≥ 2 items/s coasts with 0.94 friction per frame,
  then snaps to the nearest item. Knob detents step 1 → 4 by speed (`accel`).
- 60 Hz ticker only while open; a strip PNG (48×258 pt at ×1.25, CoreText `Apple Color Emoji`) is rendered and set only
  when its offset changes (P3). Vars: `emoji_on`, `emoji_l`, `emoji_r`, `emoji_tile`; strip layers sit on top of the
  track / limits pictures, enabled by `emoji_on`.
